Documentación de la API

La API de Cinema permite gestionar un catálogo de películas: consultar, crear, actualizar y eliminar registros. Todos los datos se intercambian en formato JSON.

Endpoints disponibles

Método Ruta Descripción Cuerpo de entrada
GET /peliculas Lista todas las películas —
GET /peliculas/{id} Obtiene una película por su ID — (id en la ruta)
POST /peliculas Crea una nueva película JSON con los campos de una película
PUT /peliculas/{id} Actualiza una película existente JSON con los campos de una película
DELETE /peliculas/{id} Elimina una película por su ID —

Campos de una película

Campo Tipo Obligatorio Descripción
titulo string Sí Título de la película
director string Sí Director de la película
año integer Sí Año de estreno
genero string Sí Género cinematográfico
sinopsis string No Resumen de la trama (null por defecto)
puntuacion number No Nota de 0 a 10 (null por defecto)

Ejemplos de petición y respuesta

Crear película

POST /peliculas

Petición

{
  "titulo": "Interstellar",
  "director": "Christopher Nolan",
  "año": 2014,
  "genero": "Ciencia ficción",
  "sinopsis": "Un grupo de exploradores viaja a través de un agujero de gusano.",
  "puntuacion": 8.7
}

Respuesta 201 Created

{
  "titulo": "Interstellar",
  "director": "Christopher Nolan",
  "año": 2014,
  "genero": "Ciencia ficción",
  "sinopsis": "Un grupo de exploradores viaja a través de un agujero de gusano.",

Consultar una película

GET /peliculas/999

Respuesta 404 Not Found

{

}

Eliminar una película

DELETE /peliculas/1

{
